# Text-to-image retrieval on Flickr8k with a frozen SigLIP 2 — one dataset, one metric, several methods

Course project for CS2203 (Computer Vision, UIT). The encoder
(`google/siglip2-base-patch16-224`, frozen, pinned revision), the Flickr8k test split
(1,000 images, 5,000 caption queries) and the primary metric (Recall@1) are fixed for the
whole team. Each member owns one way of turning the cached embeddings into a ranking:

| Team method | Registry name(s) | Question it answers | Read |
|---|---|---|---|
| Baseline | `global` | exact cosine between the text vector and every image vector | [`docs/PROJECT.md`](docs/PROJECT.md) |
| MINER | `five_crop` | does fusing five fixed crops with the global view help small objects? | [`docs/PROJECT.md`](docs/PROJECT.md), [`docs/RUN_FIVE_CROP_EXPERIMENT.md`](docs/RUN_FIVE_CROP_EXPERIMENT.md) |
| FAISS | `faiss_flat`, `faiss_ivf` | what does an approximate search block (inverted file) cost and save? | [`docs/METHODS.md`](docs/METHODS.md), [`docs/FAISS_RESULTS.md`](docs/FAISS_RESULTS.md) |

All methods share one embedding cache, one evaluator, one prediction format and one
validation-selected score threshold protocol, so their numbers are directly comparable.

## Quick start

```bash
git clone <repository-url> && cd <repository-directory>
python3 -m venv .venv && source .venv/bin/activate
make install          # pip install -e .  (torch, transformers, faiss-cpu, gradio, ...); uv venv users: make install-uv
make assets           # pinned Flickr8k splits + checkpoint (~2 GB), manifests
make cache            # global + five-crop image embeddings, once (~5 min on an M3 Pro)
make tune             # five-crop alpha + threshold, validation only
make metrics          # every method, with and without threshold -> artifacts/reports/summary.md
make demo             # http://127.0.0.1:7860
```

Step-by-step with expected outputs, Windows notes and troubleshooting:
[`docs/INSTALL.md`](docs/INSTALL.md). `make help` lists every target.

## Results (test split, 5,000 queries; reproduced 2026-10-10 on M3 Pro and 2026-10-11 on M1 Pro, identical quality numbers)

| Team method | Method | R@1 | R@5 | R@10 | MRR | nDCG@10 | ΔR@1 vs `global` [95% CI] |
|---|---|---:|---:|---:|---:|---:|---:|
| Baseline | `global` | 0.7220 | 0.9174 | 0.9606 | 0.8077 | 0.8434 | – |
| MINER | `five_crop` | **0.7368** | **0.9206** | **0.9658** | **0.8186** | **0.8531** | +0.0148 [+0.0062, +0.0236] |
| FAISS | `faiss_flat` | 0.7220 | 0.9174 | 0.9606 | 0.8077 | 0.8434 | identical ranking |
| FAISS | `faiss_ivf` (nlist=32, nprobe=8) | 0.6802 | 0.8606 | 0.9002 | 0.7589 | 0.7920 | −0.0418 [−0.0512, −0.0332] |

With the validation-selected threshold (keep 95% of validation relevant images):
`global`/`faiss_flat` retain 95.2% of relevant images with 8.3 results per query,
`five_crop` 94.8% with 7.5, `faiss_ivf` 89.0% with 7.6 (the index never sees ~8% of them).

## What each file does

### Root

| File | Role |
|---|---|
| `app.py` | starts the Gradio demo (`python app.py --port 7860 --device mps`) |
| `Makefile` | one target per documented command: `install`, `install-uv`, `assets`, `cache`, `tune`, `test`, `metrics`, `diagnostics`, `demo`, `clean` |
| `pyproject.toml` | package metadata and dependency ranges (`pip install -e .`) |
| `configs/experiment.yaml` | the single experiment config: checkpoint id + pinned revision, dataset paths, crop ratio, alpha grid, `threshold_target_recall = 0.95`, seed |
| `.gitignore` | keeps `data/`, `models/`, `artifacts/` (root-level only) and tooling caches out of Git |
| `README.md` | this file |
| `AGENTS.md` | team rules: frozen checkpoint, validation-only tuning, never commit on someone's behalf |

### `src/vision_retrieval/` (the library; nothing imports upward: `data` → `methods` → `evaluation` → `demo`)

| File | Role |
|---|---|
| `__init__.py` | re-exports the public names so `from vision_retrieval import load_split, list_methods, ...` works |
| `config.py` | `ExperimentConfig` + `load_config()`: reads `configs/*.yaml`, resolves paths, validates values |
| `encoder.py` | `FrozenSiglip2Encoder`: loads the pinned checkpoint, `encode_texts()` / `encode_images()` to L2-normalised vectors, picks cuda / mps / cpu |
| `timing.py` | `write_timing_report()`: portable wall-clock JSON for offline steps |
| `data/flickr8k.py` | Flickr8k split loading (`load_split`), `ImageRecord` / `QueryRecord`, canonical manifests and their SHA-256 (`manifest_sha256`, `write_evaluation_manifests`) |
| `data/cache.py` | the embedding cache on disk: `save_embedding_cache` / `load_embedding_cache` with `CacheMetadata` compatibility checks |
| `data/crops.py` | deterministic five-crop geometry (`crop_boxes`, `five_crops`) |
| `data/setup_assets.py` | `materialize_flickr8k`: turns the downloaded Parquet shards into the legacy image + caption layout |
| `methods/registry.py` | `MethodSpec`, `BuildContext`, `BuiltMethod`, `register` / `get_method` / `list_methods` / `build_method`; `threshold_source` link |
| `methods/retrievers.py` | `GlobalRetriever` (exact cosine), `FiveCropRetriever` (MINER fusion), `SearchResult`, `select_alpha` |
| `methods/builtin.py` | registers `global` and `five_crop`; reads the validation-selected alpha |
| `methods/faiss_retrievers.py` | `FaissRetriever` (kinds `flat`, `ivf`), full-ranking completion for unreachable images, registers `faiss_flat` and `faiss_ivf` with `threshold_source="global"` |
| `methods/__init__.py` | imports the modules above so every preset is registered, in dropdown order |
| `evaluation/metrics.py` | R@K, MRR, nDCG@10, latency percentiles, `select_score_threshold`, `evaluate_score_threshold` |
| `evaluation/predictions.py` | the shared prediction format (`PredictionRecord`, gzip JSONL writer / reader / validator) and `MethodMetadata` |
| `evaluation/thresholds.py` | validation-selected cutoffs linked per method: `threshold_path`, selection from records, provenance-checked `load_threshold` |
| `demo.py` | Gradio runtime: builds every method once, method dropdown, threshold checkbox, timing and status lines |

| Script | Does | Writes |

| `evaluate.py` | any method; `--split test` applies the method's threshold, `--split validation` selects it | `artifacts/predictions/<m>.jsonl.gz` + `.metadata.json`, `artifacts/reports/<m>_metrics.{json,md}`, `<m>_per_query.csv`; validation runs go under `.../validation/` and write `artifacts/parameters/<m>_threshold.json` |

| `select_threshold.py` | shared, method-agnostic cutoff selector from validation predictions | the JSON you name |
| `compare_methods.py` | paired, image-clustered bootstrap of two prediction files | `artifacts/reports/compare_<a>_vs_<b>.json` |

| `sweep_ivf_nprobe.py` | IVF `nprobe` sweep on the real gallery | `artifacts/reports/ivf_tradeoff.md` |
| `benchmark_index_scaling.py` | Flat vs IVF at 1k / 10k / 100k vectors (synthetic growth) | `artifacts/reports/index_scaling.{md,json}` |

## Conventions (short version of `AGENTS.md`)

- SigLIP 2 stays frozen; every parameter (alpha, thresholds, index settings) is chosen on
  the validation split or is a fixed rule of thumb. Nothing is selected on test.
- Complete 1,000-image rankings are the primary result; thresholded metrics are reported
  separately. Prediction files must pass `scripts/score_predictions.py`.
- Package layout: `data` → `methods` → `evaluation`; nothing imports upward, `demo.py` sits on top. Add a method
  under `methods/` and import it in `methods/__init__.py`; see `docs/METHODS.md`.
- `data/`, `models/` and `artifacts/` are never committed. Nobody commits or pushes on
  someone else's behalf; review `git status` and commit yourself.
